## Decision Trees & Ensemble Learning

**From Scratch to Random Forest**

Исследование алгоритмов деревьев решений и ансамблевых методов машинного обучения.

*Tech Stack:* Python, NumPy, Pandas, Scikit-learn, Matplotlib

**Project Overview**

Основная цель — исследовать работу Decision Tree, Bagging и Random Forest, оценить качество моделей и проанализировать влияние параметров на результаты.

## Решающие деревья
В этой части мы напишем и протестируем собственную реализацию решающего дерева.

**Ячейка №1**
Реализована функция find_best_split() для поиска оптимального разбиения данных при построении дерева решений.
Функция работает с числовыми и категориальными признаками, поддерживает задачи классификации и регрессии.
Для оценки разбиений используются:
Gini Impurity - для классификации.
Variance Reduction - для регрессии.
Для числовых признаков расчёты векторизованы с помощью NumPy. Для категориальных проверяется разделение каждой категории относительно остальных.
Функция возвращает возможные пороги, значения критерия качества и лучшее разбиение. В дальнейшем она используется при построении дерева решений.

**Ячейка №2**
Для проверки алгоритма используется датасет California Housing из библиотеки scikit-learn. Он содержит характеристики жилых районов Калифорнии и целевую переменную, связанную со стоимостью жилья.мНа этом этапе загружаем данные, разделяем признаки и целевую переменную, затем просматриваем первые строки таблицы, чтобы ознакомиться с её структурой.

**Ячейка №3**
С помощью find_best_split() оцениваем качество разбиения по признаку MedInc на датасете California Housing. График показывает, как меняется уменьшение дисперсии при разных порогах. Наилучшее разбиение достигается примерно при значении 5, где критерий информативности максимален.

**Ячейка №4**
Сравниваем качество разбиения по всем признакам датасета California Housing с помощью find_best_split(). Наибольшее уменьшение дисперсии показал признак MedInc (медианный доход населения). Поэтому он выбран для первого разбиения дерева решений.

**Ячейка №5**
Реализовано собственное дерево решений DecisionTree без использования готовой модели из scikit-learn. Алгоритм рекурсивно строит дерево, выбирая оптимальное разбиение с помощью ранее реализованной функции find_best_split().
Основные методы:
_fit_node() - построение узлов дерева и выбор признаков для разбиения.
_predict_node() - получение предсказания путём последовательного перехода по узлам.
fit() - обучение модели.
predict() - предсказание для новых объектов.
Реализация поддерживает классификацию и регрессию, а также числовые и категориальные признаки.

**Ячейка №6**
Для дальнейшего тестирования дерева решений используется датасет students.csv, содержащий пять признаков, связанных с уровнем знаний студентов, и целевую переменную UNS. На этом этапе загружаем данные, удаляем лишний индексный столбец и разделяем таблицу на признаки X и целевую переменную y. Далее исследуем распределение классов и зависимость целевой переменной от отдельных признаков.

**Ячейка №7**
С помощью find_best_split() сравниваем качество разбиения по пяти признакам датасета: STG, SCG, STR, LPR и PEG. Для каждого признака строим график зависимости прироста критерия Джини от порога разбиения. Наибольшее значение критерия показывает PEG, поэтому этот признак выбирается для первого разбиения дерева решений.

**Ячейка №8**
Строим диаграммы рассеяния для пяти признаков датасета Student Knowledge, чтобы посмотреть, как распределяются объекты разных классов. На графиках видно, что признак PEG лучше остальных разделяет классы: при низких значениях чаще встречается класс 0, а при высоких - класс 1. Это согласуется с результатами предыдущего анализа критерия Джини.

**Ячейка №9**
Проверяем собственную реализацию DecisionTree на датасете Mushroom, содержащем категориальные признаки грибов и информацию об их съедобности. Сначала преобразуем категориальные значения с помощью LabelEncoder, затем делим данные на обучающую и тестовую выборки в соотношении 50/50. Обучаем дерево решений и оцениваем качество классификации с помощью Accuracy.
Результат: Accuracy = 99.93% на тестовой выборке. Модель практически без ошибок классифицирует грибы как съедобные или ядовитые.

## Бэггинг и случайный лес
В данной части мы будем работать c задачей предсказания диабета у пациента. Посмотрим на работу бэггинга над решающими деревьями и случайного леса, сравним их работу.

**Ячейка №10**
Загружаем датасет diabetes.csv, содержащий 768 наблюдений и 8 признаков для прогнозирования диабета. Проверяем структуру данных и распределение целевой переменной Outcome. На графике видно, что классы распределены неравномерно: около 500 наблюдений относятся к классу 0 и 268 к классу 1. Это важно учитывать при дальнейшем обучении и оценке моделей.

**Ячейка №11**
Разделяем данные на признаки X и целевую переменную y, затем формируем три выборки:
- Train (49%) - для обучения моделей.
- Validation (21%) - для подбора гиперпараметров и сравнения моделей.
- Test (30%) - для итоговой оценки качества.
Используем train_test_split с random_state=42 для воспроизводимости разбиения.

**Ячейка №12**
Подбираем оптимальные значения max_depth и min_samples_leaf для модели DecisionTreeClassifier.

Перебираем разные комбинации параметров, обучаем модель на тренировочной выборке и сравниваем результаты по F1-score на валидационной.
**Лучшие параметры:**
- max_depth = 6
- min_samples_leaf = 7
- **Validation F1-score = 0.702**
Для наглядности строим тепловую карту F1-score по всем комбинациям параметров. Затем обучаем модель с выбранными параметрами на объединённой обучающей и валидационной выборке.
Результаты на тестовой выборке:
Accuracy - 0.683
Precision - 0.534
Recall - 0.688
ROC-AUC - 0.768
Модель обнаруживает около 69% положительных случаев, однако точность положительных предсказаний остаётся сравнительно невысокой.

**Ячейка №13**
Обучаем ансамбль из 50 деревьев решений с помощью BaggingClassifier и сравниваем его качество с одиночным деревом.
Результаты на тестовой выборке:

| Метрика | Decision Tree | Bagging |
|---|---|---|
| Accuracy | 0.683 | 0.749 |
| Precision | 0.534 | 0.631 |
| Recall | 0.688 | 0.663 |
| ROC-AUC | 0.768 | 0.808 |

Bagging улучшил Accuracy, Precision и ROC-AUC по сравнению с одиночным деревом. При этом Recall немного снизился.

**Ячейка №14**
Обучаем RandomForestClassifier из 50 деревьев. Для подбора max_depth и min_samples_split используем Grid Search с 5-кратной кросс-валидацией по F1-score.
Лучшие параметры:
- max_depth = 8
- min_samples_split = 5
- Средний F1-score на кросс-валидации: 0.643
Результаты на тестовой выборке:
Accuracy - 0.753
Precision - 0.639
Recall - 0.663
ROC-AUC - 0.811
Random Forest показал немного лучшие Accuracy, Precision и ROC-AUC по сравнению с Bagging, при практически одинаковом Recall.
Random Forest показывает наилучшее качество по сравнению с 1 деревом и беггингом, т. к. при выборе признаков есть дополнительный рандом, которая уменьшает корреляцию между деревьями и снижает дисперсию. Бэгинг улучшает дерево за счет снижения дисперсии при том же смещении, а случайный лес при помощи снижения корреляции между деревьями. В нашем случае лучшие показатели у Random Forest

**Ячейка №15**
Исследуем влияние количества деревьев (n_estimators) на качество Random Forest. Обучаем модели с разным количеством деревьев и сравниваем ROC-AUC на тестовой выборке.
По графику видно, что ROC-AUC быстро растёт при увеличении числа деревьев до 15–20, после чего стабилизируется около 0.81.
Таким образом, дальнейшее увеличение количества деревьев практически не улучшает качество модели, но увеличивает вычислительные затраты.

## Заключение
В ходе проекта я исследовала работу деревьев решений и ансамблевых методов машинного обучения.
Сначала реализовала собственное дерево решений и алгоритм поиска оптимального разбиения, затем проверила их на нескольких датасетах. Это помогло разобраться, как выбираются признаки и пороги разбиения и как строятся предсказания.
Во второй части сравнила Decision Tree, Bagging и Random Forest на задаче классификации диабета. Для моделей подбирала гиперпараметры, использовала валидацию и кросс-валидацию, оценивала качество по нескольким метрикам.
Основные результаты:
Bagging и Random Forest показали более высокую Accuracy и Precision, чем одиночное дерево.
Random Forest достиг наибольших Accuracy (0.753) и ROC-AUC (0.811) среди ансамблевых моделей.
Увеличение количества деревьев улучшало ROC-AUC преимущественно на начальном этапе, после чего качество стабилизировалось.
Проект позволил на практике изучить построение деревьев решений, влияние гиперпараметров и преимущества ансамблевых методов. Также стало понятно, почему для оценки классификации важно использовать несколько метрик, а не ориентироваться только на Accuracy.
