## Решающие деревья
В этой части мы напишем и протестируем собственную реализацию решающего дерева.

**Ячейка №1**
Реализована функция find_best_split() для поиска оптимального разбиения данных при построении дерева решений.
Функция работает с числовыми и категориальными признаками, поддерживает задачи классификации и регрессии.
Для оценки разбиений используются:
Gini Impurity - для классификации.
Variance Reduction - для регрессии.
Для числовых признаков расчёты векторизованы с помощью NumPy. Для категориальных проверяется разделение каждой категории относительно остальных.
Функция возвращает возможные пороги, значения критерия качества и лучшее разбиение. В дальнейшем она используется при построении дерева решений.

Для проверки алгоритма используется датасет California Housing из библиотеки scikit-learn. Он содержит характеристики жилых районов Калифорнии и целевую переменную, связанную со стоимостью жилья.мНа этом этапе загружаем данные, разделяем признаки и целевую переменную, затем просматриваем первые строки таблицы, чтобы ознакомиться с её структурой.

**Ячейка №3**
С помощью find_best_split() оцениваем качество разбиения по признаку MedInc на датасете California Housing. График показывает, как меняется уменьшение дисперсии при разных порогах. Наилучшее разбиение достигается примерно при значении 5, где критерий информативности максимален.

**Ячейка №4**
Сравниваем качество разбиения по всем признакам датасета California Housing с помощью find_best_split(). Наибольшее уменьшение дисперсии показал признак MedInc (медианный доход населения). Поэтому он выбран для первого разбиения дерева решений.

**Ячейка №5**
Реализовано собственное дерево решений DecisionTree без использования готовой модели из scikit-learn. Алгоритм рекурсивно строит дерево, выбирая оптимальное разбиение с помощью ранее реализованной функции find_best_split().
Основные методы:
_fit_node() - построение узлов дерева и выбор признаков для разбиения.
_predict_node() - получение предсказания путём последовательного перехода по узлам.
fit() - обучение модели.
predict() - предсказание для новых объектов.
Реализация поддерживает классификацию и регрессию, а также числовые и категориальные признаки.

Наибольшее значение критерия показывает PEG, поэтому этот признак выбирается для первого разбиения дерева решений.

Сначала преобразуем категориальные значения с помощью LabelEncoder, затем делим данные на обучающую и тестовую выборки в соотношении 50/50. Обучаем дерево решений и оцениваем качество классификации с помощью Accuracy.
Результат: Accuracy = 99.93% на тестовой выборке. Модель практически без ошибок классифицирует грибы как съедобные или ядовитые.
